# RIver AGI UI 设计说明书

## 1. 设计原则

采用克制的 B 端科技商务风，效率优先、层级清晰、组件统一、反馈完整。侧边导航、顶部导航、内容区使用统一栅格和间距，避免静态展示冒充业务功能。

## 2. 视觉规范

| 项目 | 规范 |
| --- | --- |
| 主色 | `#165DFF`；hover `#E8F3FF` |
| 背景 | `#FFFFFF`、`#F7F8FA` |
| 边框 | `#E5E6EB`；卡片圆角 8px |
| 正文 | `#4E5969`；标题 `#1D2129` |
| 字体 | `-apple-system`、PingFang SC、Microsoft YaHei |
| 栅格 | 24 列，模块间距 16px，页面内边距 24px |
| 反馈 | 加载、成功、失败、空数据、禁用、hover 均有明确状态 |

## 3. 页面结构

六大模块均采用独立 Vue 页面和路由；业务主页面承载执行动作，规则/模型/安全配置进入独立后台页面。图表、表格、上传区、步骤条、状态标签和弹窗使用统一组件规范。

## 4. 关键交互

- 数据页面：上传→解析→预览→清洗→任务配置→工作台→质检→导出。
- 预测页面：数据集→模型/框架→训练进度→预测结果→评估→A/B→发布/回滚。
- 空状态必须说明原因，例如未来预测日期没有实际值时不显示偏差样本属于正常业务状态。
- 所有按钮必须有真实接口、加载态、成功/失败提示和错误恢复路径。

## 5. UI 交付说明

当前 UI 设计以 `frontend/src/views`、`frontend/src/components` 和 `frontend/src/assets` 为可执行源码；如甲方要求 Figma/Sketch 原始设计稿，应在项目启动阶段确认设计工具和交付格式后另行导出。
