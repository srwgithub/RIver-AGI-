# RIver AGI 培训材料

## 管理员

1. 使用管理员账号登录并创建角色。
2. 在权限管理中授权模块权限，用测试账号验证权限生效。
3. 配置预测模型、质量规则和安全策略。
4. 在安全审计中心执行扫描、查看风险、导出审计日志。
5. 创建备份并在隔离环境完成恢复验证。

## 业务人员

数据流程：多源导入 → 解析预览 → 清洗 → 标签配置 → 派发 → 独立工作台标注 → 质量审核/仲裁 → 导出。

预测流程：选择已解析数据集 → 创建预测任务 → 选择模型和框架 → 训练 → 预测 → 评估 → 偏差分析 → 调优/重训 → A/B 测试 → 发布或回滚。

趋势分析首次进入会读取当前数据集并展示默认趋势折线；用户可切换对比柱状、异常散点、占比饼图，并使用诊断、根因分析和报表功能。

## 运维人员

每天执行 `./ops/health-check.sh`，查看监控汇总和未处理告警；每天确认备份成功，每周抽查恢复，每月汇总可用率和故障记录。异常按《故障应急预案》执行，所有操作保留审计依据。

## 交付演示顺序

登录 → 导入数据 → 清洗预览 → 标注任务 → 质量审核 → 导出 → 创建预测 → 查看结果 → 评估调优 → 趋势看板 → 安全扫描 → 备份恢复 → 查看监控告警。
