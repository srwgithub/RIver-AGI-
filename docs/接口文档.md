# RIver AGI REST API 接口文档

## 1. 通用约定

- 基础地址：`http://host:8080/api`
- 登录：`POST /v1/auth/login`
- 除公开接口外，使用 `Authorization: Bearer <accessToken>`。
- 成功响应统一包含 `code: 200`、`message`、`data`；失败返回错误消息和 HTTP 状态码。
- OpenAPI：`GET /api-docs`；Swagger UI：`/swagger-ui.html`

| 模块 | 主要接口 |
| --- | --- |
| 认证 | `POST /v1/auth/login`、`POST /v1/auth/register`、`GET /v1/auth/me` |
