## 二、14.1 数据安全

### 14.1.1 数据加密

**存储加密（字段级）**
- 加密算法：AES/GCM/NoPadding（GCM 模式，128 位认证标签，PBKDF2WithHmacSHA256 派生 256 位密钥，65536 次迭代）
- 实现类：[SecurityUtils.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/SecurityUtils.java)（encrypt/decrypt 方法）
- 字段级加密注解：[@EncryptField](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/annotation/EncryptField.java)
- AOP 自动加解密：[EncryptFieldAspect.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/aspect/EncryptFieldAspect.java)
  - 拦截 Mapper 写入方法（insert/update*/save*）对 `@EncryptField` 标注字段自动加密
  - 拦截 Mapper 读取方法（select*/get*/list*/page*）对返回值自动解密
- 加密字段示例：[User.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/auth/entity/User.java) 的 `phone`、`realName` 字段
- 配置开关：`encryption.enabled`（默认 false 向后兼容，生产环境设 true 启用），`encryption.master-key`，`encryption.algorithm`
- IV 随机生成（12 字节），密文与 IV 拼接后 Base64 编码存储

**传输加密**
- 支持 HTTPS 部署（生产环境通过反向代理/负载均衡启用 TLS）
- JWT 令牌传输认证凭证，避免明文密码传输
- 密码 BCrypt 哈希存储（不可逆）

### 14.1.2 访问控制

- 认证：JWT（[JwtUtil.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/auth/util/JwtUtil.java) + [JwtAuthenticationFilter.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/auth/JwtAuthenticationFilter.java)）
- 授权：RBAC（Role/Permission/RolePermission 表 + sys_user_role 关联）
- 方法级权限：`@PreAuthorize("hasRole('ADMIN')")` 细粒度控制（如 [AuditController](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/security/controller/AuditController.java)、[BackupController](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/backup/controller/BackupController.java) 仅 ADMIN 可访问）
- 多租户隔离：所有业务表含 `tenant_id` 字段，[ResourceAccessValidator](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/ResourceAccessValidator.java) 校验数据归属
- 配置：[SecurityConfig.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/config/SecurityConfig.java)（无状态会话、CSRF 防护、路径白名单）

### 14.1.3 数据备份

- 备份服务：[BackupService.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/backup/service/BackupService.java)
- 备份内容：数据集、安全扫描记录、敏感数据检测、系统配置（ZIP 打包）
- 定时备份：`@Scheduled(cron = "0 0 3 * * ?")` 每日凌晨 3 点全量备份
- 手动备份：`POST /api/v1/backups/create`
- 异地备份：`backup.offsite-enabled=true` 时自动复制备份副本到 `backup.offsite-dir` 目录（合同 14.1.3 异地备份策略）
- 完整性校验：备份时计算 SHA-256 校验值存入 `backup_record.checksum` 字段
- 恢复验证：`POST /api/v1/backups/{backupId}/verify`
  - 重新计算文件 SHA-256 与记录值比对
  - 验证 ZIP 可正常读取（条目数 > 0）
  - 验证异地副本一致性
  - 返回 `VERIFIED`/`CORRUPTED`/`FILE_MISSING`/`NOT_FOUND` 状态
- 备份清理：`MAX_BACKUPS=10`，超限自动清理最旧备份
- 备份记录表：`backup_record`（含 status/file_path/size_bytes/checksum/offsite_path/error/时间戳）
- 数据迁移：[V24__add_backup_checksum_offsite_privacy_consent.sql](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/resources/db/migration/V24__add_backup_checksum_offsite_privacy_consent.sql)

### 14.1.4 安全审计

- AOP 审计：[AuditLogAspect.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/aspect/AuditLogAspect.java)
  - `@AuditOperation` 注解标记需审计的方法
  - 异步写入（taskExecutor 线程池），队列满降级同步写
  - 自动脱敏审计日志中的敏感数据（身份证/手机号/银行卡/邮箱/密码字段）
  - 记录 traceId、操作人、IP、UserAgent、请求方法/路径、耗时、结果
- 审计日志表：`audit_log`（含 user_id/username/ip_address/user_agent/request_method/request_path/operation_details/result/duration_ms，created_at 有索引）
- 审计接口：[AuditController.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/security/controller/AuditController.java)
  - `GET /api/v1/audit/logs` 分页查询（支持 userId/resourceType/actionType/日期范围过滤）
  - `GET /api/v1/audit/compliance-summary` 合规摘要
  - `GET /api/v1/audit/compliance-report` 合规报告下载（JSON）
  - `GET /api/v1/audit/logs/export` 审计日志导出（CSV）

## 三、14.2 个人信息保护

### 14.2.1 知情同意

- 隐私政策接口：`GET /api/v1/privacy/policy`（无需登录，公开访问）
  - 返回政策版本、生效日期、适用法规、6 大章节（信息收集/使用目的/存储保护/共享披露/数据主体权利/留存删除）、数据主体权利清单
  - 实现：[PrivacyService.getPrivacyPolicy()](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/privacy/service/PrivacyService.java)
- 注册强制同意：[RegisterRequest.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/auth/dto/RegisterRequest.java) 的 `privacyConsent` 字段（`@AssertTrue` 强制校验，必须勾选同意）
- 同意记录留痕：[AuthService.register()](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/auth/service/AuthService.java) 注册成功后调用 `PrivacyService.recordConsent()` 落库
  - 记录 userId/username/policy_version/consent_type/ip_address/user_agent/consent_at
- 显式同意接口：`POST /api/v1/privacy/consent`（政策版本更新后用户重新同意）
- 同意历史查询：`GET /api/v1/privacy/consent/history`
- 同意状态查询：`GET /api/v1/privacy/consent/status`
- 同意记录表：`privacy_consent`（V24 迁移 + schema.sql/schema-h2.sql 建表）

### 14.2.2 数据脱敏

- 脱敏注解：[@Sensitive](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/annotation/Sensitive.java)（支持 PHONE/EMAIL/ID_CARD/BANK_CARD/NAME/GENERIC 6 类）
- Jackson 序列化器：[SensitiveSerializer.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/serializer/SensitiveSerializer.java)
  - 实现 `ContextualSerializer`，序列化时读取字段注解类型自动脱敏
  - API 响应自动脱敏，无需业务代码干预
- 脱敏规则：
  - 手机号：`138****8888`
  - 邮箱：`zha***@example.com`
  - 身份证：`1101**********1234`
  - 银行卡：`**** **** **** 8888`
  - 姓名：`张**`
- 应用示例：[UserResponse.java](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/auth/dto/UserResponse.java) 的 email/phone/realName 字段
- 数据集脱敏：[SecurityService.maskSensitiveData()](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/security/service/SecurityService.java) 支持数据集字段脱敏并生成脱敏文件
- 审计日志脱敏：[AuditLogAspect](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/common/aspect/AuditLogAspect.java) 对审计内容中的敏感数据自动脱敏

### 14.2.3 数据加密存储

- 个人可识别信息（PII）加密：通过 `@EncryptField` 注解标记，AOP 自动加解密（见 14.1.1）
- 敏感数据扫描识别：[SecurityService.scanSensitiveData()](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/security/service/SecurityService.java)
  - 10 类敏感数据规则（身份证/银行卡/手机号/邮箱/密码/薪资/地址/姓名/证件号/社保）
  - 基于字段名 + 内容正则双重匹配，含置信度评分
  - 风险分级（HIGH/MEDIUM/LOW），生成处置建议

### 14.2.4 数据留存与数据主体权利

- 留存策略接口：`GET /api/v1/privacy/retention`
  - 个人信息留存 365 天，审计日志 180 天，备份 30 天，最大备份数 10
- 数据导出权利：`GET /api/v1/privacy/data/export`（数据可携带权）
  - 导出用户个人信息 + 同意历史
- 数据删除权利：`DELETE /api/v1/privacy/data`（被遗忘权）
  - 清除用户个人可识别字段（email/phone/realName），审计记录匿名保留
- 实现：[PrivacyService](file:///Users/yidaoliu/Documents/RIver%20AGI%E7%B3%BB%E7%BB%9F/backend/src/main/java/com/river/agi/privacy/service/PrivacyService.java) 的 `exportPersonalData()`/`deletePersonalData()`

## 四、14.3 数据合规

- 合规对标法规：《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》
- 合规摘要：`GET /api/v1/audit/compliance-summary`
  - 审计日志数、高风险数、安全扫描数、审计完整性、隐私保护配置状态、对标法规
- 合规报告：`GET /api/v1/audit/compliance-report`（JSON 下载）
- 敏感数据扫描：`POST /api/v1/security/datasets/{id}/scan`（识别数据集敏感字段）
- 安全策略管理：`GET/POST/DELETE /api/v1/security/policies`
- 安全仪表盘：`GET /api/v1/security/dashboard`（扫描数/风险数/审计日志数统计）
- 法规对标检查：通过敏感数据扫描规则引擎（10 类规则对标个人信息保护法第 28 条敏感个人信息定义）+ 留存策略对标数据安全法第 29 条数据留存要求

## 七、结论

5. **知情同意**（14.2.1）：隐私政策 + 注册强制同意 + 同意留痕
6. **数据脱敏**（14.2.2）：@Sensitive 注解 + Jackson 自动脱敏
7. **加密存储**（14.2.3）：@EncryptField 注解 + 敏感数据扫描
8. **留存删除**（14.2.4）：留存策略 + 数据导出/删除权利
9. **数据合规**（14.3）：法规对标 + 合规报告 + 敏感扫描

测试基线：1088 项单元测试通过，JaCoCo 行覆盖率 80.09%，满足质量门禁要求。
