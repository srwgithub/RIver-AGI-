# RIver AGI 数据库设计文档

## 1. 数据库概况

- 数据库：MySQL 8.0+
- 字符集：`utf8mb4`
- 迁移工具：Flyway
- 主配置：`backend/application-mysql.yml`
- 迁移目录：`backend/src/main/resources/db/migration/`
- 初始化参考：`backend/database/init_mysql.sql`

生产环境使用独立业务账号，不使用 root；数据库连接、密码和密钥通过 `backend/.env.local` 或部署平台密钥注入。

## 2. 核心表分组

| 分组 | 主要表 | 用途 |
| --- | --- | --- |
| 用户权限 | `sys_user`、`sys_role`、`sys_permission`、`sys_user_role`、`sys_role_permission` | 身份、角色和权限控制 |
| 数据集 | `dataset`、`dataset_column`、`dataset_profile`、`data_quality_issue` | 数据上传、字段、画像和质量问题 |
| 标注 | `label_schema`、`annotation_task`、`annotation_task_assignee`、`annotation_item`、`annotation_history` | 标签、任务、派发、标注和历史 |
| 标注质量 | `annotation_quality_rule` | 校验、抽检、一致性和质量规则 |
| 预测模型 | `prediction_task`、`model_version`、`prediction_result`、`prediction_evaluation` | 预测任务、模型版本、结果和评估 |
| 趋势分析 | `dashboard`、`dashboard_widget`、`trend_diagnosis`、`anomaly_alert`、`root_cause_analysis`、`decision_scenario` | 看板、诊断、异常、根因和决策 |
| 报表配置 | `chart_config`、`report_template`、`report_instance`、`export_record` | 图表、报表和导出记录 |
| 安全审计 | `security_scan_task`、`sensitive_data_detection`、`data_mask_record`、`audit_log`、`security_policy`、`security_event` | 扫描、脱敏、审计和安全策略 |
| 运维监控 | `performance_sample`、`runtime_alert`、`async_task`、`backup_record` | 性能、告警、异步任务和备份 |
| 系统配置 | `system_config`、`chat_session`、`chat_message` | 全局配置和 AI 对话 |

## 3. 关键关系

```text
sys_user ──< sys_user_role >── sys_role ──< sys_role_permission >── sys_permission
dataset ──< annotation_task ──< annotation_item ──< annotation_history
dataset ──< prediction_task ──< prediction_result
prediction_task ──< model_version ──< prediction_evaluation
prediction_task ──< performance_sample ──< runtime_alert
dataset ──< security_scan_task ──< sensitive_data_detection
```

## 4. 数据治理约定

- 业务表使用租户字段隔离数据；删除优先使用逻辑删除。
- 用户密码使用 BCrypt，不保存明文密码。
- 审计表记录用户、操作、资源、请求和结果；敏感字段按策略脱敏。
- 上传文件、备份文件和模型文件存放在持久化目录，不直接写入 Git。
- 结构变更必须新增 Flyway 迁移，不直接修改已发布迁移文件。

## 5. 初始化与升级

```bash
cd backend
mysql -uroot -p river_agi < database/init_mysql.sql
mvn -DskipTests package
```

生产启动时启用 `FLYWAY_ENABLED=true`，应用自动执行未完成迁移。升级前必须备份数据库并记录 Flyway 版本。

## 6. 权限与备份

数据库账号至少分为应用读写账号、迁移账号和只读审计账号。备份范围包括业务表、配置表、审计表、上传文件和模型目录；恢复后必须抽查数据集、任务、模型和审计记录。
