# RIver AGI 测试计划

## 1. 测试范围

覆盖功能、接口、权限、安全、数据、模型训练/预测、性能、稳定性、备份恢复、兼容性和回归测试。

## 2. 测试阶段

| 阶段 | 内容 | 入口/输出 |
| --- | --- | --- |
| 单元测试 | Java 服务、算法、Python 引擎 | Maven Surefire、pytest |
| 接口测试 | 登录后核心 REST API | QA 脚本、接口测试记录 |
| 集成测试 | Java-MySQL-Python-前端联调 | 联调报告 |
| 端到端测试 | 真实业务闭环 | 现场验收记录 |
| 性能测试 | 200 并发、响应、数据规模 | 压测报告 |
| 安全测试 | 权限、扫描、依赖漏洞、渗透 | 安全报告 |
| 恢复测试 | 备份、恢复、数据完整性 | 恢复演练报告 |

## 3. 通过标准

功能闭环无阻断；接口响应符合合同目标；并发和数据规模达到合同要求；安全问题完成整改；覆盖率总体不低于 80%、关键业务逻辑 100%；测试失败项有关闭记录或双方确认的遗留清单。

## 4. 测试环境与数据

测试环境使用 MySQL、Java 8080、Python 5001、前端 3000；数据使用 `test-data/` 中的脱敏验收数据。生产压测必须在目标硬件、目标数据规模和目标部署拓扑执行。
