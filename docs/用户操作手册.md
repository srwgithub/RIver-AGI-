# RIver AGI 用户操作手册

## 1. 登录

打开前端地址，输入管理员或业务账号登录。生产环境必须使用正式账号，禁止继续使用默认测试密码。若提示 `Unauthorized`，清理浏览器旧 Token 后重新登录。

## 2. 数据采集与标注

1. 进入“多源数据导入”，上传 CSV、XLS/XLSX、JSON、图片、音视频等数据。
2. 等待解析完成，打开数据预览并确认字段。
3. 创建清洗任务，执行清洗预览；确认规则后点击应用清洗。
4. 进入“标注任务配置”，选择数据集、标签体系、规则、协同方式和质量抽检规则。
5. 派发任务后进入独立标注工作台，按数据类型完成标注、提交、跳过或争议标记。
6. 在质量中心执行自动校验、抽检、人工审核、一致性检查、纠偏和仲裁。
7. 通过最终验收后导出标注结果文件。

## 3. 需求预测

1. 进入“市场需求预测引擎”，选择已解析数据集。
2. 新建预测任务，选择时间序列、回归、分类或深度序列模型。
3. 选择 Java 算法或 TensorFlow/PyTorch 引擎，提交训练并查看进度和日志。
4. 训练完成后生成预测结果，查看实际值与预测值、MAE、RMSE、MAPE、R² 和异常偏差。
5. 进入评估优化页面执行偏差分析、自动调优、手动调优或 Retraining。
6. 在 A/B 测试面板对比模型后发布生产版本；需要撤回时执行版本回滚。

## 4. 趋势分析与报表

进入趋势看板后默认显示当前数据集的趋势折线。可切换对比柱状、异常散点和占比饼图，并使用趋势诊断、异常告警、根因分析、OLAP、What-If 和自定义报表。没有对应真实数据时页面会显示空状态提示，不代表页面故障。

## 5. 安全与管理

- 权限管理：创建角色 → 勾选权限 → 保存 → 使用对应账号重新登录验证。
- 安全扫描：选择数据集 → 执行扫描 → 查看风险 → 按策略脱敏 → 查询审计日志。
- 备份恢复：创建备份 → 查看完成状态 → 在隔离环境恢复 → 抽查数据和配置。

## 7. 常见问题

- 偏差分析没有样本：预测日期尚无对应实际值时，页面显示空状态是正常业务结果。
- 训练无法提交：确认 Python 引擎 5001 健康、Java 已开启 `DL_ENGINE_ENABLED=true`。
- 页面刷新 404：生产 Nginx 必须将未知前端路由回退到 `index.html`。
- 数据导出失败：确认任务已完成、用户有导出权限且后端上传目录可写。
