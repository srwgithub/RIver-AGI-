# RIver AGI 系统第三方测评委托说明书

## 1. 文档目的

为满足《RIver AGI 系统建设合同》第 10.5 条第（4）项关于"安全稳定验收标准"的要求，本系统在开发完成并完成内部测试后，须委托具备资质的第三方测评机构对系统进行安全渗透测试与网络安全等级保护二级（以下简称"等保二级"）测评，并出具具备公信力的测评报告，作为合同最终验收的必要支撑材料。

本说明书明确测评范围、依据、项目清单、委托机构资质要求、时间安排、交付物及配合事项，作为乙方与第三方测评机构签署委托合同的依据。

## 3. 测评范围

测评覆盖 RIver AGI 系统全部 6 大功能模块及其依赖的全部技术组件：

| 序号 | 模块名称 | 测评覆盖内容 |
| --- | --- | --- |
| 1 | 数据采集与标注平台 | 多源数据采集、标注任务分发、标注工作台、文件上传与解析 |
| 2 | 标注质量管理 | 质量规则配置、质检与仲裁、标注历史追溯 |
| 3 | 市场需求预测引擎 | 预测任务调度、算法配置、深度学习引擎对接 |
| 4 | 趋势分析与可视化 | OLAP 分析、异常检测、根因分析、决策支持 |
| 5 | 预测结果评估与优化 | 模型评估、性能监控、再训练中心 |
| 6 | 数据管理与安全审计 | 数据集管理、备份恢复、审计日志、安全策略 |

技术组件覆盖范围：

- Web 前端：Vue 3 单页应用、Nginx 反向代理
- 后端 API：Spring Boot 3.x（含 JWT 认证、RBAC 权限、审计切面）
- 数据库：MySQL（业务数据）、Redis（缓存与会话）
- 对象存储：MinIO（数据集与模型文件）
- 消息中间件：RabbitMQ（异步任务与数据解析）
- Python 预测引擎：Flask 服务、LSTM/MLP/Transformer/sklearn 模型
- 运维环境：Docker 容器、健康检查脚本 `ops/health-check.sh`

## 5. 委托机构资质要求

第三方测评机构须满足以下资质之一，并提供有效期内的资质证书复印件：

1. 列入公安部《网络安全等级保护测评机构推荐目录》，具备等保二级及以上测评资质；
2. 获得中国信息安全测评中心（CNVSEC）信息安全服务资质认证（安全工程类或风险评估类）；
3. 具备中国网络安全审查技术与认证中心（CCRC）信息安全服务资质。

同时要求：

- 测评团队中至少 2 名持有 CISP 或同等信息安全专业人员证书；
- 近 3 年内有政务或企业级数据平台测评实施案例不少于 3 个；
- 与甲方、乙方无利益关联，签署保密协议与廉洁承诺书。

## 6. 时间安排

| 阶段 | 时间节点 | 交付内容 |
| --- | --- | --- |
| 测评准备 | 开发完成后第 1 周内 | 测评方案确认、测试环境就绪、资料移交 |
| 渗透测试 | 开发完成后 2 周内完成 | 渗透测试报告初稿 |

| 整改复核 | 整改完成后 1 周内 | 整改复核报告 |
| 最终交付 | 复核通过后 3 个工作日内 | 全部正式报告盖章版 |

## 7. 交付物

第三方测评机构须交付以下成果物，均需加盖机构公章：

1. **渗透测试报告**：含测试方法、漏洞清单（含风险等级、复现步骤、影响分析）、修复建议、复测结论；
2. **等保测评报告**：含测评对象、测评方法、单项测评结果、符合性判定（符合/部分符合/不符合/不适用）、综合得分；
3. **整改复核报告**：针对高危和中危漏洞的整改验证记录及最终结论；
4. **数据合规专项评估意见**：针对《数据安全法》《个人信息保护法》合规性的专项说明。

## 9. 验收标准

第三方测评结果须同时满足以下条件，方可通过合同 10.5(4) 安全稳定验收：

1. **渗透测试**：无高危漏洞，中危漏洞修复率 100%，低危漏洞修复率不低于 80%；
2. **等保测评**：综合符合性判定为"基本符合"及以上，综合得分不低于 70 分；
3. **数据合规**：未发现违反《数据安全法》《个人信息保护法》的重大合规缺陷；
4. **整改复核**：所有要求整改项均已完成复核并出具通过结论。

任一条件未满足的，乙方须在 2 周内完成整改并重新申请复核，直至全部条件满足后方可进入合同最终验收流程。
