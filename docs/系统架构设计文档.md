# RIver AGI 系统架构设计文档

## 1. 架构原则

采用前后端分离、组件化、模块化和低耦合设计。前端负责页面和交互，Java 后端负责业务、权限、审计和持久化，Python 引擎负责深度学习训练与预测。

## 2. 逻辑架构

```text
浏览器/多端客户端
        │ HTTPS / REST API
        ▼
Nginx / API 网关
        │
        ├── Vue 3 前端
        └── Spring Boot Java 后端
                ├── 认证与 RBAC
                ├── 数据集与标注
                ├── 质量管理
                ├── 预测与模型版本
                ├── 趋势与报表
                ├── 安全审计与备份
                └── 监控与告警
                        ├── MySQL
                        ├── Python TensorFlow/PyTorch 引擎
                        ├── Redis
                        ├── RabbitMQ
                        └── MinIO/持久化存储
```

## 3. 技术栈

| 层次 | 技术 |
| --- | --- |
| 前端 | Vue 3、Vite、Element Plus、ECharts、Axios |
| Java 后端 | Spring Boot、Spring Security、MyBatis-Plus、Flyway、Swagger/OpenAPI |
| Python | Flask、PyTorch、TensorFlow/Keras、scikit-learn |
| 数据与基础设施 | MySQL、Redis、RabbitMQ、MinIO、Docker、Nginx |

## 4. 安全架构

JWT 身份认证、BCrypt 密码、RBAC 权限、接口鉴权、审计日志、敏感数据扫描、脱敏、AES/GCM 加密配置、限流、HTTPS 和备份恢复。生产环境必须启用加密、限流、密钥托管和最小权限。

## 5. 部署与扩展

Java 和 Python 通过容器或进程管理器托管，使用健康检查和自动重启；Python 引擎可独立扩展训练/推理实例。MySQL、Redis、RabbitMQ、MinIO 使用持久化卷；生产高可用需按目标环境配置多实例、主从或托管服务。
