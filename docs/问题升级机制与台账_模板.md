# RIver AGI 问题升级机制与台账（模板）

> 本模板用于合同 7.5。问题先由项目团队协商；协商无法解决的，3 个工作日内升级至双方项目负责人；重大问题升级至双方高层领导。

## 一、升级规则

1. 发现问题后由发现人登记问题编号、影响、优先级、责任人和临时措施。
2. 项目团队在约定时限内协商解决并更新证据。
3. 无法解决或预计影响里程碑的问题，最迟在 3 个工作日内升级至双方项目负责人。
4. 重大问题包括数据安全、生产不可用、重大数据丢失、核心链路阻断、合同范围或里程碑重大影响，应立即通知并升级双方高层。
5. 关闭问题前必须记录根因、永久措施、复测结果、关闭人和关闭日期。

## 二、问题等级

| 等级 | 判定 | 升级要求 |
| --- | --- | --- |
| P0 重大 | 安全事件、核心服务不可用、重大数据风险 | 立即升级双方高层 |
| P1 高 | 核心业务闭环阻断、严重影响里程碑 | 1 个工作日内项目负责人介入 |
| P2 中 | 有替代方案的功能或性能问题 | 3 个工作日内评估是否升级 |
| P3 低 | 文案、体验或非阻断问题 | 周报跟踪关闭 |
