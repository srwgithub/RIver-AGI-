## 2. 项目目标

系统支撑数据采集、数据标注、标注质量管理、市场需求预测、趋势分析、预测评估优化和数据安全审计，形成从数据采集、标注、训练、预测到结果展示的完整业务闭环。

## 3. 功能需求

| 模块 | 需求范围 | 主要能力 |
| --- | --- | --- |
| 数据采集与标注 | 多源导入、清洗、任务配置、工作台 | 文件解析、预览、清洗、标签、派发、文本/表格/图片/视频标注、导出 |
| 标注质量管理 | 审核、抽检、一致性、纠偏、仲裁、绩效 | 自动校验、人工审核、多轮追溯、争议处理、质量评分 |
| 市场需求预测 | 多模型、训练、预测和版本 | 时序、回归、分类、序列预测、TensorFlow/PyTorch、A/B、发布/回滚 |
| 趋势分析 | 看板、诊断、异常、根因、报表 | 趋势折线、对比柱状、异常散点、占比饼图、OLAP、What-If |
| 评估优化 | 评估、监控、偏差、调优、重训 | MAE/RMSE/MAPE/R²、性能采样、告警、自动/手动调优、Retraining |
| 安全审计 | 权限、安全、备份、审计 | RBAC、扫描、风险、脱敏、操作留痕、备份恢复、合规报告 |

## 4. 非功能需求

- 前后端分离、RESTful API、组件化和模块化架构。
- 常规操作目标不高于 1.5 秒，复杂操作目标不高于 5 秒。
- 支持至少 200 人同时在线，目标全年可用率不低于 99.5%。
- 支持生产容器化、监控、告警、日志、备份、恢复和安全审计。
- 具体性能、安全和质量指标以合同 3.2～3.6 条款及现场验收报告为准。

## 5. 验收标准

以真实数据完成导入→清洗→配置→派发→标注→质检→仲裁→导出；完成数据集→训练→预测→评估→A/B→发布；完成权限、扫描、审计和备份恢复链路。性能、覆盖率、安全和可用率按合同证据报告确认。
